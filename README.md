# A Novel Delay-Line Time-to-Digital Converter with Logic-Driven Time Encoding

## Abstract

A Time-to-Digital Converter (TDC) employing 45 nm CMOS technology is proposed in this work. It uses a singular delay-line architecture for accurate measurement of time intervals in digital circuits. The architecture employs 5 current-starved delay cells, each exhibiting a propagation delay of 245 ps, coupled with six edge-triggered D flip-flops to capture signal transitions and generate a thermometer code. A custom digital encoder converts this thermometer coded sequence into a 3-bit output in binary. The design requires low power, which makes it suitable for on chip performance monitoring. The integrated TDC architecture supports applications such as electronic control unit synchronization and time-of-flight measurements in sensors for safety critical systems.

**Keywords:** TDC, delay line, current controlled inverter, encoder, thermometer code.
